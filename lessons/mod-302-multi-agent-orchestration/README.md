# mod-302-multi-agent-orchestration: Multi-Agent Orchestration Architecture

> Scaffolded by `aicg org execute-plan`. Lecture chapters and exercise content are authored on subsequent autonomous cycles.

**Estimated effort:** 14 hours

## Learning objectives

- Design orchestrator-worker topologies and reason about their token economics (~15x cost vs. single chat)
- Choose between handoffs and manager-as-tools; decide who owns the final user-facing answer
- Apply inter-agent protocols (MCP for tools, A2A for delegation) at architecture level
- Define escalation and coordination strategies across a multi-agent system
