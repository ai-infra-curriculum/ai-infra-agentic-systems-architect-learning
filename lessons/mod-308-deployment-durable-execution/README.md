# mod-308-deployment-durable-execution: Deployment, Durable Execution & Human-in-the-Loop

> Scaffolded by `aicg org execute-plan`. Lecture chapters and exercise content are authored on subsequent autonomous cycles.

**Estimated effort:** 12 hours

## Learning objectives

- Architect durable execution and resumption for long-running, stateful agents (e.g., Temporal)
- Design deployment strategies that avoid disrupting in-flight agents (e.g., rainbow deployments)
- Integrate human-in-the-loop approval flows (approve/edit/reject/respond) with state persistence
- Plan scaling and failure recovery for agent fleets
