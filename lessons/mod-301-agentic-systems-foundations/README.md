# mod-301-agentic-systems-foundations: Agentic Systems Foundations & When NOT to Use an Agent

> Scaffolded by `aicg org execute-plan`. Lecture chapters and exercise content are authored on subsequent autonomous cycles.

**Estimated effort:** 12 hours

## Learning objectives

- Distinguish workflows from agents and justify the choice per task (predictability vs. model-driven flexibility)
- Apply Anthropic's orchestration patterns: prompt chaining, routing, parallelization, orchestrator-workers, evaluator-optimizer
- Decompose a system into tool vs. sub-agent vs. hardcoded-path boundaries
- Frame the 'start simple, add complexity only when it demonstrably improves outcomes' discipline

## Structure

- `01-…md` … `0N-…md`: lecture chapters.
- `exercises/`: per-exercise prompts.
- `labs/`: long-form hands-on labs.
- `quizzes/`: knowledge checks.
- `resources.md`: external references.
