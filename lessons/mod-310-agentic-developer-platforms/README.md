# mod-310-agentic-developer-platforms: Agentic Developer Platforms & SDLC Integration

> Scaffolded by `aicg org execute-plan`. Lecture chapters and exercise content are authored on subsequent autonomous cycles.

**Estimated effort:** 16 hours

## Learning objectives

- Design a plugin-based architecture that extends an agentic coding tool (e.g., Claude Code) using its extension standards: Agents, Skills, Hooks, and the Model Context Protocol (MCP)
- Architect AI systems for the software development lifecycle: securely interfacing an agent with internal SDLC toolchains and proprietary data to perform requirements analysis, code generation, and debugging autonomously
- Build reliable tool-use patterns and context-hydration strategies that give an agent the precise system access and context to execute SDLC tasks
- Integrate with core DevOps and project-management toolchains (GitHub, Jira, Confluence, CI/CD pipelines) over REST, GraphQL, and event-driven interfaces
- Design developer-focused tooling with a strong emphasis on usability, adoption, onboarding, documentation, and continuous feedback loops
