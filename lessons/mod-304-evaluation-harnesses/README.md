# mod-304-evaluation-harnesses: Evaluation Harnesses for Agentic Systems

> Scaffolded by `aicg org execute-plan`. Lecture chapters and exercise content are authored on subsequent autonomous cycles.

**Estimated effort:** 12 hours

## Learning objectives

- Design trajectory evaluation (sequence of messages/tool calls) and final-state evaluation
- Build tool-call correctness checks at selection and argument layers (deterministic + LLM-judge)
- Author LLM-as-judge rubrics (accuracy, completeness, citation, tool efficiency)
- Define an offline/online eval strategy that gates deployment

## Structure

- `01-…md` … `0N-…md`: lecture chapters.
- `exercises/`: per-exercise prompts.
- `labs/`: long-form hands-on labs.
- `quizzes/`: knowledge checks.
- `resources.md`: external references.
